# 3. Animation prompts (Seedance 2.0)

**Settings for every clip:** 16:9, 5 seconds, audio off (all audio is added in the edit).
**Reference image:** the character sheet(s) of whoever is in the shot.
**First frame:** the keyframe. For shots 7–9 a **last frame** is also given (`assets/endframes/`) so the payment cards come out exactly right.

## Default negative prompt
```
style change, realistic, 3D render, face changing, different person, extra fingers, extra limbs, extra people, text, subtitles, blurry, warping, melting bodies, camera movement
```
Extra negatives per shot are listed under each shot.

## Lessons learned
- Keyframe first, then animate. Typing a scene straight into a video tool gives a different character every time.
- Say LEFT/RIGHT relative to the **frame**, not the character.
- Avoid 180° turns (the character flips between front and back). Start from a back view instead.
- AI video can't do readable text or logos, so it's better to use a last frame with the exact card, or overlay the card in the edit.
- One face per shot works better for talking and lip movement.
